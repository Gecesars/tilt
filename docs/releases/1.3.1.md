# EFTX Tilt 1.3.1 — Windows 10 e Windows 11 x64

Revisão de compatibilidade do aplicativo e do instalador WiX.

**Requisito:** Windows 10 versão 1809 ou posterior (build 17763+), 64 bits x64,
ou Windows 11 x64. Windows 10 22H2 e LTSC 2019/2021 atendem ao requisito.
Não é necessário instalar Python, Qt ou .NET no computador do usuário.

- Pacote recompilado sem DLLs de sistema e bibliotecas externas capturadas de
  outros aplicativos do computador de compilação.
- MSI verifica o build do Windows e apresenta o requisito mínimo quando necessário.
- Aplicativo portátil verifica a versão antes de carregar Qt.
- Mantidos cálculos RF, diagramas, PDF, dados SQLite e licença restrita EFTX.

Baixe o **MSI** para instalar ou o **ZIP** para uso portátil. Confira os arquivos
com `SHA256SUMS.txt`. Feche o programa antes de atualizar. O banco de projetos fica
fora da pasta instalada e é preservado na remoção do programa.

**Validação:** 141 testes automatizados aprovados, instalação nova e atualização
MSI 1.3.0 → 1.3.1 testadas, com reparação/desinstalação e preservação do SQLite.
Suporte Windows 10 fundamentado
nos requisitos oficiais de Qt 6.11.2 e Python 3.12.10. Execução local validada em
Windows 11. **Execução em Windows 10 real ainda pendente**, sem alegação de
homologação nesse sistema. MSI e executável permanecem sem assinatura digital.

Uso restrito à EFTX e a usuários expressamente autorizados por escrito.
Licenças e direitos dos componentes de terceiros permanecem preservados.
