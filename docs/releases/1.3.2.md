# EFTX Tilt 1.3.2 — instalador EXE offline

Baixe **EFTX_Tilt-1.3.2-Setup-x64.exe**, execute e aceite os termos EFTX.
Abra **EFTX Tilt Desktop** pelo menu Iniciar ou pela área de trabalho.

- Instalador EXE independente do Windows Installer, sem privilégios de administrador.
- Inclui Python, Qt/PySide6, Qt PDF, SQLite, catálogo e runtime Visual C++.
  Não baixa dependências durante a instalação.
- DLLs MSVC consolidadas na pasta do aplicativo; diagnóstico verifica o caminho
  das dependências efetivamente carregadas.
- Instalação MSI anterior pode permanecer. O novo atalho abre a nova versão,
  com acesso ao mesmo banco de projetos. Feche o aplicativo antigo antes de usar.
- Reinstalação restaura arquivos; desinstalação preserva projetos e arquivos extras.
- Mantidos cálculos, diagramas, relatórios e licença restrita EFTX.

**Requisito:** Windows 10 1809+ x64 (build 17763+) ou Windows 11 x64.
ZIP portátil também disponível. Confira a integridade com `SHA256SUMS.txt`.

**Validação local:** 145 testes aprovados; instalação, reinstalação e remoção no
Windows 11 build 26300, com 233 arquivos conferidos por SHA-256. Aplicativo
instalado gerou PDF e prévia com ambiente Python/Qt limpo e 19 módulos de runtime
carregados da própria pasta. Banco existente e arquivos adicionais preservados.

Windows 10 é alvo conforme os requisitos de Qt/Python; **a execução em Windows
10 real ainda não foi validada**. O instalador e o aplicativo não têm assinatura
digital de editor. O erro do MSI relatado não foi diagnosticado sem seu log;
este EXE usa uma instalação independente.

Uso restrito à EFTX e a usuários autorizados por escrito. Direitos dos componentes
de terceiros preservados; termos e avisos acompanham os arquivos.
